# Overview
This project contains my Java code for Lab 6 (Java Methods and Their Applications) in Engr. Jamie Rosal's class. It shows how to use methods to split a program into smaller, reusable pieces instead of putting all the code inside main().

What the Code Does
Greetings & Math: Welcomes the user with a void method, then runs basic math (add, subtract, multiply, divide) using returned values.

Arrays & Number Checks: Finds the total sum and largest number in an array, checks if a number is prime, and calculates the GCD and LCM.

Recursion & Strings: Uses recursion to solve factorials and Fibonacci numbers, and tests if a word is a palindrome (reads the same forward and backward).
